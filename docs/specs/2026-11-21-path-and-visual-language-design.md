# Путь ученика и визуальный язык (2026-11-21)

Статус: выбрано направление **A «Обложка»** (2026-11-21); PR 59 (язык) и PR «Путь» сделаны. Макеты: `docs/mockups/2026-11-21-directions/index.html`.

## Зачем

Слова пользователя: «упражнения делаю вразнобой, что за чем идёт не понимаю, выбираю наугад. Нет системы», «некоторые
тексты пугают терминологией, некоторые я не читаю», «уши Claude торчат из нашего приложения».

Порядок обучения в данных уже есть (`path`, блок «Сегодня»), но главный экран рисует каталог: 10 разделов, 70 карточек
с абзацем на каждой, в порядке, который с `path` не совпадает. Четыре курса открыты сразу.

## Что делает вид шаблонным (наблюдения в браузере, компьютер и телефон, светлая и тёмная)

1. Всё лежит в одинаковой скруглённой карточке (радиус 14–16, тонкая рамка, тень): упражнение, «Сегодня», навыки,
   задание, полоса «Сейчас», клавиатура. Нет иерархии: главное и второстепенное одной формы.
2. Одна и та же тройка в каждой карточке: мелкая надпись-kicker, жирный заголовок Unbounded, абзац серым.
3. Кремовый фон + бирюзовый акцент + тёмно-бирюзовый «герой» с мятной кнопкой: палитра по умолчанию у моделей.
4. Сегменты-«таблетки» везде: курсы, разделы, язык, бюджет, этапы, стиль бэнда. На телефоне шапка занята ими в два ряда.
5. Дисплейный шрифт жирный и широкий даже на длинных фразах («Left hand: the same pattern in every bar…» в три строки).
6. Цвет ничего не значит: бирюзовый одновременно «сейчас», «кнопка», «дом» на клавишах и рамка активной карточки.
7. На главном экране нет ответа «где я»: счётчики 0/6, 0/5 по разделам, но не положение на пути.

## Цели

- За пять секунд видно: глава, ступень N из M, сколько сделано, одна кнопка «Продолжить».
- Будущее не отвлекает: пройденные ступени свёрнуты, будущие серые (мягкий замок, «всё равно открыть»).
- На карточке упражнения одна строка: что делают руки. Новое слово вводится один раз, отдельной карточкой.
- Внешний вид задаётся одним языком (переменные + общие классы), а не набором карточек.

Не цели: новые упражнения и пьесы, смена правил зачёта, смена формата прогресса и резервной копии.
Анти-цели: жёсткие замки; геймификация (очки, огоньки, маскоты); ещё один слой текста поверх старого.

## Подходы

Путь:
1. Оставить каталог, поднять «Сегодня» выше. Дёшево, но «анархия» остаётся: 70 карточек на экране.
2. **Ступени поверх `path` (выбрано).** Те же упражнения и id, новое представление; каталог уходит во вторую вкладку.
3. Жёсткая лента «один урок в день» без списка. Понятно, но нельзя вернуться к любимому упражнению; нет обзора.

Визуальный язык: три направления в макете (A «Обложка», B «Страница», C «Пульт»). Выбирает пользователь.

## Данные

`content/tracks/<id>.json` получает `steps` рядом с `path`:

```json
"steps": [
  { "id": "s1", "title": {"ru": "Первые 12 тактов", "en": "…"}, "goal": {"ru": "…", "en": "…"},
    "items": ["d-white", "ear-find", "pat-p1", "d-black", "ear-hl1", "form-p1"], "concert": "form-p1",
    "words": ["bar", "form"] }
]
```

- `path` = склейка `steps[].items` по порядку (тест: каждый шаг `path` ровно в одной ступени; `concert` последний в
  своей ступени; 6–9 упражнений в ступени; все id существуют). `path` остаётся в файле: его читают `queue.js` и тесты.
- `words`: id из `content/glossary.json`, которые вводятся на этой ступени карточкой «Новое слово». Тест: слово
  (по `match` глоссария) не встречается в `title` / `about` упражнений этой и предыдущих ступеней раньше своей карточки.
- Ступень пройдена, когда все её упражнения `itemDone`. Порядок сдачи не важен: сданное засчитывается где угодно.
  Текущая ступень = первая непройденная. Новые ключи `localStorage` только для «открыл всё равно» (`settings.unlocked`).
- Замер (`diag`) в ступени не входит, остаётся в «Уроке на сегодня», когда пора.

### Главы

Блюз → Босса-нова → Стандарты: главы одного курса. Босса открывается мягко после 5-й ступени блюза, стандарты после
4-й ступени боссы; раньше глава серая с «всё равно открыть». Риффы, аккомпанемент, аккорды, справочник переезжают в
раздел «Играть» (вторая вкладка верхнего меню): свободная игра без зачёта, с курсом не смешивается.

## Экран «Путь»

- Шапка: Курс / Играть, MIDI, настройки (язык, тема, названия нот уезжают в окно настроек).
- «Урок на сегодня»: одна кнопка «Продолжить»; рядом строкой «повторить 2 · новое 2 · ≈20 мин» (бюджет меняется там же).
- Глава и положение: «Блюз · ступень 2 из 9», полоса из 9 делений, «9 из 69».
- Ступени списком: пройденные одной строкой с галочкой; текущая раскрыта (цель, упражнения, концерт выделен);
  будущие серые одной строкой; по нажатию цель и «всё равно открыть».
- Строка упражнения: номер, название, одна строка «что делаешь руками», состояние (сдано / повторить / сейчас).
  «Зачем» и подробности под раскрытием. Карточка «Новое слово» стоит в списке ступени перед упражнением, где слово
  впервые нужно: слово, одна фраза, мини-клавиатура, «послушать».
- Вторая вкладка «Все упражнения»: нынешний каталог по разделам, без абзацев.

## Тексты

Правило карточки: `title` + одна строка `does` (что делают руки, до ~60 знаков, без терминов, которых ещё не было).
Нынешний `about` становится «Зачем» под раскрытием и тоже чистится. Порядок введения слов для блюза (ступень → слова):
1: такт, круг (форма); 2: фраза, дом, вопрос и ответ; 3: квинта, терция; 4: аккорд, четверть; 5: октава; 6: буги,
синкопа; 7: припев, синяя нота; 8: оборот, шелл; 9: вариация. Окончательный список сверю с текстами в PR «Тексты».

## Порядок PR

1. Визуальный язык: токены и общие классы в `app/css/app.css`, палитры `theme.js`, все экраны; тест контраста.
2. Путь: `steps` в данных + тест, экран «Путь», «Урок на сегодня», вкладка «Все упражнения».
3. Курсы и свободная игра: главы по очереди, раздел «Играть».
4. Тексты: `does` + «Зачем», карточки «Новое слово», блюз → босса → стандарты, RU и EN в паре.

Проверка каждого PR: `for f in tests/*.test.mjs; do node "$f"; done`; браузер: компьютер и телефон, светлая и тёмная.

## Решение пользователя

- Замок мягкий («Закрывать мягко», 2026-11-21): будущие ступени серые, открываются через «всё равно открыть».

## Мои решения (можно поправить)

- Пять палитр заменяются одной выбранной (светлая + тёмная); сохранённый `scheme` игнорируется без ошибки.
- Концерт ступени = существующее упражнение (форма / соло / выступление), новых упражнений не добавляю.
