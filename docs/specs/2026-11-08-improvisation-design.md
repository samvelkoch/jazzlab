# Импровизация в дорожках: дизайн

Дата: 2026-11-08. Продолжение [дизайна курса](2026-11-07-jazz-course-design.md) (цель: «сыграть для семьи… с импровизацией»).

## Что это

Четвёртый тип занятия после паттерна, лика и формы: **соло** (`kind: "solo"`). Бэнд играет всю форму
(левая рука по паттерну, барабаны), ученик играет правой **своё**. Приложение не сравнивает с эталоном,
а оценивает четыре вещи, которые отличают осмысленную импровизацию от нажимания клавиш:

1. **В ладу.** Нота из палитры такта (гамма или ноты аккорда). «Чужая» нота, разрешённая полутоном в
   палитру в пределах следующей восьмой, считается подходом и засчитывается.
2. **В сетке.** Нажатие попадает в восьмую (свинговую, если свинг) в том же допуске, что у формы.
3. **Фразы и паузы.** Нота и следующая на расстоянии меньше доли принадлежат одной фразе. Фраза от 3 нот.
   Пауза это такт без нажатий (одна нота в первой восьмой такта допускается как хвост фразы).
4. **Целевые ноты.** На такте со сменой аккорда первая нота в первой доле это нота нового аккорда.

Это не экзамен на «правильно», а зеркало: после каждого круга табло «в ладу 92 % · в сетке 81 % ·
фраз 5 · пауз 5/6 · целевых 3/4», и зачёт по порогам из контента. Всё записывается как в «Выступлении»,
можно послушать себя.

## Формат `jazzlab-solo/1` (`content/solos/<id>.json`)

```json
{
  "$format": "jazzlab-solo/1", "id": "blues-scale",
  "title": { "ru": "…", "en": "…" }, "about": { "ru": "…", "en": "…" },
  "form": "blues-c", "pattern": "p2",
  "palette": { "mode": "scale", "scale": "blues", "root": "C" },
  "hand": { "lo": 60, "hi": 72 },
  "phrasing": { "play": 2, "rest": 2 },
  "call": false,
  "targets": false,
  "choruses": 1,
  "pass": { "inside": 0.9, "grid": 0.75, "phrases": 3, "rests": 0.8, "targets": 0.6, "pitches": 3 }
}
```

- `palette`: `{ "mode": "scale", "scale", "root" }` одна гамма на всю форму; `{ "mode": "scales", "parts": [{ "bars": [0, 15], "scale": "major", "root": "F" }, …] }` по участкам формы; `{ "mode": "chordscale" }` гамма от аккорда такта (m7 → дорийский, 7 → миксолидийский, maj7 и мажорное трезвучие → мажор, m7b5 → локрийский, dim7 → уменьшённая, m → эолийский); во всех режимах ноты аккорда такта (второй аккорд со слота 4, `chordAt`) входят в палитру и подсвечиваются сильнее.
- Гаммы (`app/js/music/scales.js`): `blues` 0 3 5 6 7 10, `minor-pent` 0 3 5 7 10, `major-pent` 0 2 4 7 9, `major`, `dorian`, `mixolydian`, `aeolian`, `locrian`, `dim` (0 2 3 5 6 8 9 11). `paletteAt(solo, formBars, bar, slot)` → `{ pcs: Set, chordPcs: Set, chord }`.
- `hand`: подсказка положения руки, диапазон клавиатуры `[lo-5, hi+7]`, палитра подсвечивается во всех октавах, но ярче внутри `hand`.
- `phrasing`: `{ play, rest }` в тактах, ячейка повторяется по форме; такты `rest` должны быть пустыми. `null` = свободно (паузы всё равно считаются, но порог `rests` не применяется).
- `call: true`: режим «вопрос-ответ»: в тактах `play` первой ячейки играет **бэнд** фразу из палитры (генератор контуров up/down/arch/same из `screens/improv.js` + ритм из 4–6 восьмых; фраза строится из `chordPcs` на сильных долях и `pcs` на остальных), ученик отвечает в следующих `play` тактах; `rest`-такты при `call` не нужны (`phrasing: { play: 2, rest: 2 }` + `call` = бэнд 2 такта, ты 2 такта).
- `targets: true` включает метрику целевых нот (только такты, где аккорд отличается от предыдущего; смена внутри такта на слоте 4 тоже считается сменой).
- `choruses`: сколько кругов подряд в одном запуске; зачёт по порогам считается за запуск целиком (среднее по кругам), `pitches` минимум разных нот за круг.
- Пороги: `inside`, `grid`, `rests`, `targets` доли 0..1; `phrases` минимум фраз за круг. Метрика без данных (нет смен аккорда с нотой в первой доле) считается пройденной.

Трек: `"imp-b1": { "kind": "solo", "solo": "blues-scale", "title"?, "about"? }`. Секция `imp` «Импровизация» после `rh`
(в std после `tunes`). Очередь дня: `solo` берётся как обычный предмет (не чаще одного в день, как мелодия).

## Экран `app/js/screens/solo.js`

Каркас как у формы (`form.js`): шапка, панель с сеткой тактов, панель клавиатуры, футер (свинг, барабаны/метроном, темп, Старт).

- Сетка тактов: аккорд, под ним роль такта («ты» / «пауза» / «бэнд») по `phrasing`; текущий такт подсвечен; после такта метка: ✓ (чисто), «−» (пауза нарушена), ◇ (целевая нота взята), ◆ (промах по целевой).
- Над сеткой строка палитры: «Ноты: C E♭ F F♯ G B♭» (текущего такта, с именами в стиле настроек), и строка живой обратной связи: «в ладу», «подход → E», «мимо: D♭», «рано 40 мс».
- Клавиатура: `kb.mark()` красит палитру: ноты аккорда `base/third/seventh` (корень/терция/септима), остальная гамма `tension` светлее; на смене аккорда перекраска. Нажатие: `flash` ok (в палитре), meh (мимо, но разрешилось), bad (мимо).
- Табло после круга и после запуска: четыре метрики с порогами, зелёные/серые, плюс «фраз N», «разных нот K». При `pass` всех: «Зачёт», `stages.done`, `scheduleReview`. Прогресс хранит `runs`, `best: { inside, grid, … }`.
- Запись: каждый запуск пишется как в `perform.js` (`recordings`, тот же формат `{ t, d, m, v }`, `acc` через `rhythmAccuracy`), в сводке «послушать» / «скачать MIDI» / удалить; `kind: 'solo'` в записи, чтобы отличать от выступлений.
- Режим «Слушать»: бэнд и, при `call`, его фразы; свои ноты не оцениваются.
- Телефон: те же правила, что у формы (клавиатура прилипает над футером, `trackFootH`).

## Чистые функции (`app/js/music/solo.js`, тесты `tests/solo.test.mjs`)

- `scaleOf(chord)`, `paletteAt(solo, bars, bar, slot)`.
- `scoreChorus(notes, ctx)` где `notes = [{ t (сек от начала круга), m }]`, `ctx = { solo, bars, bpm, swing }` → `{ inside, grid, phrases, rests: { ok, total }, targets: { ok, total }, pitches, perBar: [{ clean, restOk, target }] }`. Подход: нота вне палитры, следующая нота в пределах 1.25 восьмой и на полутон от неё в палитре. Сетка: `gridDev` из `recording.js`. Фразы: разрыв ≥ 1 доля делит фразы, фраза ≥ 3 нот.
- `passed(score, solo.pass)`.
- `makeCall(solo, bars, bar, rng)` фраза бэнда на `play` тактов.

Тесты: палитра блюза и chordscale по Blue Bossa (Dm7b5 → локрийский D), подход засчитан, фраза/пауза считаются, целевая нота на F7 такте 5 блюза, пороги.

## Контент (первый заход)

Блюз (`form: blues-c`, `pattern: p2`, свинг):
1. `blues-scale` «Блюзовая гамма: два такта играю, два молчу». scale blues C, phrasing 2/2, pass inside .9 grid .7 phrases 3 rests .8 pitches 3.
2. `blues-call` «Вопрос и ответ с бэндом». то же + `call: true`, pass phrases 3 (ответы), inside .9.
3. `blues-chords` «Ноты аккорда на смене». chordscale, phrasing null, `targets: true`, pass inside .85 grid .7 targets .6 phrases 4.
4. `blues-solo` «Соло на три круга». chordscale, choruses 3, phrasing null, targets, pass inside .85 grid .7 targets .5 phrases 3 (за круг).

Босса (`blue-bossa`, `pattern: b2`, ровные): `bossa-minor` (scale aeolian C на тактах 0–7 и 12–15, parts: Ebm7 Ab7 Dbmaj7 такты 8–11 → major Db; phrasing 2/2), `bossa-call`, `bossa-chords` (chordscale, targets), `bossa-solo` (2 круга).

Стандарт (`std-f`, `pattern: s2`, свинг): `std-key` (scales: F major такты 0–15 и 24–31, Bb major 16–23; phrasing 2/2), `std-call`, `std-chords` (chordscale, targets; это и есть «импровизация по аккордам, а не по гамме» из дизайна курса), `std-solo` (1 круг AABA).

`hand` для блюза `[60, 72]`, босса `[60, 72]`, стандарт `[60, 74]`.
